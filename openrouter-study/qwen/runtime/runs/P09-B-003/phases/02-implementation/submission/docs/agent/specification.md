# Specifikacija P09: Stanje pogleda v povezavi in zgodovina ## Problem in kontekst Korisniška stran Folio omogoča pregled opravil v okviru projekta. Trenutno je stanje vezano zgolj na URL fragment. Dodatek zahteva možnost shranjevanja stanja (filtre, pogled, urejenost) v sessionStorage. Vmesnik: 3 filterja (q, status, order), preklop pogleda (Preglednica/Tabla), gumba "Uporabi pogled" in "Ponastavi pogled". Shramba: stanje-{projectId}. Privzeto: q="", status=all, order=original, view=table. Omejitev: shramba samo za dosegljiv projekt.
