# Project Constillation

## Guiding principles
- Spoštovati dodeljeno vlogo Q za tehnično kvalifikacijo
- Minimalni direktdokumenti: task/, src/, dovoljene procesne datoteke
- Ne izvajaj brskalnih testov ali graden

## Non-negotiable rules
- Uporabljati samo node task/qualification-check.mjs za testiranje  
- Omejitev: src/qualification.ts, docs/agent/ in dovoljene procesne datoteke
- Ne menjati infrastrukture, odvisnosti ali datotek drugih vlog
- Kontrolna besedo uporabiti za nadaljevanje
