# Zgodovina specifikacije

- **Začetni zapis:** povzete so bile izvirne zahteve R01–R12 in dogovor o dostopnih imenih, filtriranju, odzivnosti ter samo bralnem pregledu.
- **Dopolnitev po pregledu:** potrjeni so `Task`/`TaskStatus` v `shared/types.ts`, GET pot in projektni tok v `src/App.tsx`/`src/useResource.ts`, obstoječi table/board ID-ji, hash pogled v `src/navigation.ts`, UTC oblikovanje v `src/formatDate.ts`, potrjeni Folio v `docs/dizajn.md` ter obseg D01–D04 v razvojnih testih.
- **Predaja implementaciji:** `specification.md` zdaj vsebuje predikate, pogoje sprejema za vse zahteve, povezave na izhodiščne dele kode in natančno loči delno pokritost D01–D04 od neizvedenih preverjanj. Testov ali aplikacije avtor specifikacije ni zagnal.
