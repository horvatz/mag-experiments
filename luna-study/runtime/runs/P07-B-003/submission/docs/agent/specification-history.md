# Zgodovina specifikacije

- Začetni zapis: osnutek po branju `PROJECT_RULES.md`, `task/instructions.md` in skupne predloge. Zajel je R01–R12, začetne predikate in sprejemne scenarije.
- Dopolnitev: pregledani so bili `shared/types.ts`, `src/App.tsx`, `src/TaskBoard.tsx`, `src/TaskDetails.tsx`, `src/navigation.ts`, `src/useResource.ts`, `src/api.ts`, relevantni deli `src/styles.css` in `docs/dizajn.md`. Dodane so bile dejanske izhodiščne meje kode, semantika shrambe, dogodkov in praznih stanj, dostopni pogoji ter izrecna ločitev predlogov testov od izvedenih dokazov.
- Vloga specifikatorja: aplikacija in testi niso bili zagnani; spremembe so omejene na specifikacijo in to zgodovino.
