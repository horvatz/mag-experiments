# Naloge P05: Straničenje in filter stanja

## Naloge
1. Ustvari sestavniške straničenja in filtra stanja.
2. Dodaj gume premika (Prva, Prejšnja, Naslednja, Zadnja stran).
3. Ustavi UI kontrolov za izbiro velikosti strani in filtra.
4. Implementiraj logiko straničenja in filtriranja v skladu s specifikacijo.
5. Dodaj aria-label=status element za dostopnost.
6. Preveri skladnost z obstoječim UI Folio.
7. Preveri ohranitve stran med preklopom pogledov.
8. Preveri ponastavitev stanja ob menjavi projekta.
